You are working on an existing ASP.NET Web Forms application. The project contains a `PFAD` module/folder with `Default.aspx`, internal pages, Master Pages, Login pages, CSS, JavaScript, and existing backend/database logic.

Your task is to **standardize and redesign ONLY the UI/theme of the complete PFAD project**.

The existing `PFAD/Default.aspx` page must be treated as the primary visual/design reference.

## 1. MAIN OBJECTIVE

Take the color/theme/design currently used on:

`PFAD/Default.aspx`

and apply the same professional visual language consistently to **all internal pages inside the PFAD project**.

Also redesign the PFAD Login page so that it follows the same theme and looks modern, professional, clean, and responsive.

The entire PFAD project must have one consistent visual identity.

# 2. STRICT COLOR PALETTE

Use ONLY the following four PFAD theme colors throughout the PFAD project:

```text
#6C1340
#A32966
#EBADCC
#FAEBF2
```

Define these colors centrally as CSS variables.

Use a structure similar to:

```css
:root {
    --pfad-primary-dark: #6C1340;
    --pfad-primary: #A32966;
    --pfad-accent: #EBADCC;
    --pfad-light: #FAEBF2;
}
```

Use these variables throughout the PFAD theme.

Do NOT repeatedly hard-code the hex values throughout different pages.

The goal is:

**Change the color once → entire PFAD project theme changes automatically.**

For example, if I later change:

```css
--pfad-primary: #A32966;
```

to another color, every PFAD component using that variable should automatically update.
